# BUFT AMT Premium SPA

A front-end-only Single Page Application concept for the Department of Apparel Manufacturing & Technology (AMT), BGMEA University of Fashion & Technology (BUFT).

## Files
- `index.html` — semantic HTML shell, SEO metadata and navigation
- `style.css` — responsive design system, animations and components
- `script.js` — hash-based SPA routing, dynamic views, accordion and modal

## Run
Open `index.html` directly in a browser, or host the folder on any static host.

## Important content note
The factual program data in this concept was checked against BUFT's published AMT department, teaching staff, tuition, admission eligibility and facilities pages during preparation.

Faculty portrait areas and alumni testimonials are deliberately placeholders. Replace them only with department-approved images and verified alumni quotes/outcomes.

## Image note
The concept references BUFT's published AMT banner image remotely. For a fully self-contained deployment, download/use only images that BUFT authorizes you to republish and place them under an `assets/images/` directory, then update the image URLs in `style.css`.
